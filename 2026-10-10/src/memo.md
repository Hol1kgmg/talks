# このPJ（キーボード）の技術選定についてレビューしてください

2026/10/10 新卒N年目の勉強会&交流会！#6（7分）
https://fresh-engineers.connpass.com/event/405844/

## 対象

- 自作キーボード（ハードウェア）に興味はあるが、ハードルを感じているライト層
- ITエンジニア。技術選定・レビューの作法は共通言語として通じる前提

## 目的（聴衆に知ってもらう2点）

1. **キーボードの特徴が、こだわりにつながる**
   「こだわり」は感覚ではなく、製品の特徴として指させる。だから探せるし、買える
2. **こだわりを持つと、どんなメリットがあるか**
   どの環境でも理想の入力環境を持ち続けられる。キーボードは自分で選定できる唯一のレイヤー

この2点がそれぞれスライド6・7に対応し、構成の中心になる。

## こだわりの定義（自分の場合）

- キーボード入力をストレスなく、楽しいと思えること
- それを実現する製品の特徴が3つある: 形状・サイズ・配列
- メリット: プライベート / オフィシャル、OS、ソフトウェアに関係なく、自分の理想の環境を持ち続けられること

## 結論

### 主結論

**キーボードは、自分で選定できる唯一のレイヤー**

- 職場のPC・OS・エディタ・ツールは会社や案件で決まり、技術選定の多くは自分の裁量外
- キーボードだけは自分で要件を決め、自分で選定し、どの環境にも持ち込める

### 副結論（ライト層への背中押し）

- こだわりとは、選ばなかった理由を説明できること（ADRの不採用理由と同じ）
- こだわりは最初から無い。選ぶと生えてくる
- こだわりは全部でなくていい。1箇所でいい。1箇所とは製品選定そのもの

### 持ち帰りの一文（候補）

- 自作キーボードは、買える。選ぶところから始めればいい
- 会社の技術選定には口を出せないが、キーボードの選定は全部自分で決められる

## 着地点（ネクストアクション）

- 買ってすぐ使える完成品を買う。カスタム（スイッチ交換、キーマップ設定等）は選定に入れない
- 企業が完成品として自作キーボードを販売しているため、組み立て・部品購入なしで始められる
- 「自作キーボード」の定義を「組み立てるもの」から「自分で選定したもの」に置き換える
- 学習コストの論点は目的ではなく支える論点。購入候補のスライドで「完成品があるから低い」と1行で済ませる

## 伝え方の方針

- 型: エンジニアが技術選定を上司・PMに伝え、承認を取りに行く稟議の形。ただし演出であって目的ではない。2つの目的が伝わるなら稟議っぽさは薄くてよい
- 語り口: 「〜を提案します」「ご承認ください」。本人は大真面目。ギャグはスライドに入れず内容の落差に任せる
- 聴衆の役割: PM役。レビュー依頼スライドで実際に問い返し、「レビューしてください」を本番で成立させる
- 流れ: 引き（3つある）→ 具体（私の答え）→ 分類（3つの中身）→ 抽象（メリット）→ 行動（購入候補）
- section スライドは入れない。見出しを稟議の項目名にして章立て感を出す

## 構成（7分 / 10枚）

|---|---|---|---|

| 3 | 承認依頼サマリー | 0:30 | 「自作キーボードの採用を提案します」+ 理由1行 |
| 4 | こだわりは3つ | 0:30 | 「3つ」という数字だけ伝える。分類名（形状・サイズ・配列）はここでは出さない |

### スライド6: 3つの分類

| 分類 | 選択肢 |
|---|---|
| 形状 | 一体 / 分割 / 一体エルゴ（左右に角度）/ テンティング（傾斜） |
| サイズ | フルサイズ / テンキーレス / 75% / 65% / 60% / 40%以下 |
| 配列 | ロウスタッガード（普通）/ 格子（オーソリニア）/ カラムスタッガード |

自分の選択を太字や色で示し、「普通のキーボード」との差も同じ表で読めるようにする。この3分類はスライド8の購入候補の比較軸にそのまま流用する。

### スライド7: 現状の技術スタック

| レイヤー | 現行 | 決定権 |
|---|---|---|
| PC | 会社支給 | 会社 |
| OS | macOS | 会社 |
| エディタ | （案件次第） | 案件 |
| キーボード | 市販品 | 自分 |

### スライド8: 入手形態の比較

| 選択肢 | 学習コスト | こだわりの余地 | 判定 |
|---|---|---|---|
| 完全自作（基板設計から） | 高 | 無限 | 不採用 |
| キット（はんだ付け・組立） | 中 | 大 | 不採用 |
| 企業販売の完成品 | 低（選ぶだけ） | 製品選定に集中 | 採用 |
| 市販の普通のキーボード | 無 | 無 | 不採用 |

肝は最下行。学習コストゼロの市販品を不採用にする理由が「こだわりの余地が無い」。

|---|---|---|---|---|---|---|
| （採用機種） | | | | | | 採用 |
| （比較候補1） | | | | | | 不採用: 理由 |

購入先は「メーカー直販」「国内専門店」「一般EC」の3区分。「専門店は敷居が高そうだが、通販で普通に買える」の一言でハードルを下げる。

## 未決（スライド化に必要な材料）

- 形状・サイズ・配列それぞれの自分の選択（分割か、キー数、格子かetc）と、「ストレスなく楽しい」のどこに効くか
- 現状の技術スタックの実値（PC、OS、エディタ、現行キーボードの機種）
- 採用した製品（メーカー・機種）
- 比較した候補機種（2つ程度。実際に迷ったもの）と購入先
- 選べなかった / 妥協した部分
- 費用（総額と内訳のざっくり）
- 架空の宛先演出（「〇〇部長殿」等）の是非
- 自己紹介 note の一言
