# Slidevスライド作成ワークフロー全般のルール

`agent/rules/slidev-assets.md`（背景画像・共有アセット固有のルール）とは別に、スライド作成作業全般に関わるルールをここに集約する。

## 見た目の検証はユーザー（開発者）が行う
コード変更後の見た目（レイアウト崩れ、余白、画像の表示位置など）の確認は、ユーザーが`mise run dev`等のdevサーバーで実際に目視確認する。Claude側でPlaywright等のヘッドレスブラウザを使った自動レンダリング確認を行う必要はない（ユーザーから明示的に依頼された場合を除く）。

- ビルドが通ること（`npx slidev build` や `mise run build`）の確認まではClaude側で行ってよい
- 一時ビルド出力を作った場合は作業終了時に片付ける
